# DocuFy (Document-Extractor Tool)

A backend application for uploading, processing, and extracting pages from PDF documents.

The project is built with Node.js, Express, TypeScript, and Supabase, following a layered architecture with a strong focus on clean code, maintainability, and scalability.

## Features
- Upload PDF documents
- Store documents in Supabase Storage
- Extract text from uploaded PDFs
- Extract selected pages into a new PDF
- Store document metadata
- Input validation
- Centralized error handling
- Layered architecture
- Dependency Injection
- Interface-driven design

## Tech Stack
- **Node.js**
- **Express.js**
- **TypeScript**
- **Supabase PostgreSQL**
- **Supabase Storage**
- **Multer**
- **pdf-lib**
- **pdf-parse**
